Este proyecto implementa el modelo base del tablero y la configuración de scripts para Node.js.

## Características:
- Tablero de 10x10 generado como matriz bidimensional.
- Generador determinista de casas/obstáculos basado en semilla (*seed*).
- Algoritmo de cálculo para movimientos válidos (arriba, abajo, izquierda, derecha) respetando los bordes (0 a 9).

## Cómo ejecutar el programa:

Para ejecutar el tablero y ver la demostración:
```bash
npm start
npm run dev
